## 1. 🧠 O que é Terraform?
Terraform é uma ferramenta de infraestrutura como código (IaC) criada pela HashiCorp. Ela permite que você crie, gerencie e destrua infraestrutura de maneira declarativa e automatizada.

## 2. 🧱 Como funciona o Terraform?
Com Terraform, você escreve a infraestrutura desejada em arquivos .tf, executa comandos como terraform plan e terraform apply, e a mágica acontece: ele se conecta à API da AWS, Azure, GCP ou outros provedores e provisiona recursos reais.

## 3. 💻 Instalando o Terraform
bash
```
# Linux/Mac
curl -fsSL https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt update && sudo apt install terraform
```


## 5. 📄 Arquivos principais do Terraform
| Arquivo             | Função                                                       |
|---------------------|--------------------------------------------------------------|
| `main.tf`           | Declara os recursos                                           |
| `variables.tf`      | Define variáveis que podem ser reutilizadas                  |
| `outputs.tf`        | Exibe saídas após o `terraform apply`                        |
| `terraform.tfvars`  | Armazena os valores das variáveis definidas em `variables.tf`|
| `providers.tf`      | Declara provedores (AWS, Azure, etc)                         |

## 6. 🔁 Ciclo de vida do Terraform
bash
```
terraform init     # Inicializa o projeto
terraform plan     # Mostra o que será criado/modificado
terraform apply    # Aplica as mudanças
terraform destroy  # Remove os recursos
```

## 10. 🧼 Boas práticas
- Sempre usar `terraform plan` antes de `apply`
- Separar os arquivos por responsabilidade
- Usar controle de versão (Git)
- Armazenar estado remoto (S3 + DynamoDB para lock)
- Nunca versionar `.tfstate` no Git

## 11. 📦 Exemplo completo – Criando um Bucket S3
`main.tf`

hcl

```
provider "aws" {
  region = var.region
}

resource "aws_s3_bucket" "exemplo" {
  bucket = "meu-bucket-exemplo-123"
  acl    = "private"
}
```
`variables.tf`

hcl
```
variable "region" {
  default = "us-east-1"
}
```
`outputs.tf`

hcl
```
output "bucket_name" {
  value = aws_s3_bucket.exemplo.bucket
}
```

**Execução**:
bash

```
terraform init
terraform plan
terraform apply
```
## 12. ❓ 5 Perguntas comuns sobre Terraform
### 1. Preciso de Access Keys?
Sim, se não usar SSO. Ou você assume roles com MFA.

### 2. É possível usar múltiplas contas AWS?
Sim, com perfis ou ferramentas como Granted.

### 3. Terraform guarda o que foi criado?
Sim, no arquivo terraform.tfstate.

### 4. Posso compartilhar estado com minha equipe?
Sim, usando remote backend (S3 + DynamoDB para lock).

### 5. Terraform é seguro?
Sim, se usar práticas como IAM bem configurado, sem credenciais hardcoded e versionamento controlado.
